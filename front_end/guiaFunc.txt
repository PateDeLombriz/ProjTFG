# 🧠 🏗️ Funcionalitats que probablement té l’aplicació

## 1. 🔐 Autenticació i gestió d’usuaris

**Indicis:**

* `apiApp/authentication/`
* `myToken.py`, `helpers.py`
* `models.py` amb migracions (`0002_alter_usuari_table.py`)

**Funcionalitats:**

* Login / logout
* Registre d’usuaris
* Tokens (probablement JWT)
* Rols (admin, gestor, treballador, etc.)
* Possiblement permisos per projecte

👉 En un software de construcció és clau per separar:

* caps d’obra
* operaris
* clients

---

## 2. 📊 API REST completa (backend Django)

**Indicis:**

* `views.py`, `serializer.py`, `urls.py`
* Estructura típica de Django REST

**Funcionalitats:**

* CRUD de dades (crear, llegir, editar, eliminar)
* Comunicació amb frontend
* Endpoints per:

  * projectes
  * tasques
  * usuaris
  * fitxers

* Assignació de responsables
